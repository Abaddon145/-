## 当前里程碑

Milestone 1 基础版本包含：

- iPhone 与 Android 共用的 Flutter 工程
- `.xlsx` 文件选择、Sheet 读取、字段自动映射和导入预览
- 首次启动自动导入 3 份内置词库
- Drift / SQLite 本地数据库
- 词条与学习状态分离
- FSRS-6 评分与 Review Log 事务写入
- 韩语 `ko-KR` 系统 TTS
- 首页、导入页和最小学习卡片闭环
- 每日新词目标、每日复习上限和当天学习进度
- 首页、词库、学习、统计、设置五个底部导航页
- 词库搜索、编辑、删除、收藏与错词本
- JSON 一键备份/恢复词库、FSRS 进度、复习记录与设置
- 云白、青森、暮霞、纸笺、海盐、深夜六套风格，支持上传自定义背景
- 手动逐条录入单词，并为每个单词标记和编辑词性
- 可安装到 iPhone 主屏幕的离线 PWA

每日学习计划默认每天 20 个新词、最多 100 次复习，可在首页右上角调整。设置和当天完成进度会持久化保存。

可在「词库」中点击「录入单词」，填写韩语、中文释义和词性；已有词条可通过「编辑 / 标记词性」补齐。设置中的「外观风格」提供六套预设与自定义背景图片（最大 2 MB）。

备份文件由用户保存在自己的设备或文件服务中；备份包含外观设置和背景图片。恢复会替换本机数据，并在执行前要求确认。

## 本地运行

需要 Flutter stable（Dart 3.10+）。首次克隆后生成平台工程与 Drift 代码：

```bash
flutter create --platforms=ios,android --org com.abaddon145 .
flutter pub get
dart run tool/configure_device_storage.dart
dart run build_runner build --delete-conflicting-outputs
flutter run
```

## iPhone 安装说明

iOS 构建必须在安装了 Xcode 的 Mac 上执行。连接 iPhone、启用 Developer Mode，并在 Xcode 中选择自己的 Signing Team 后即可运行。未付费的 Personal Team 可用于个人设备测试，但配置文件会定期到期；App Store / TestFlight 分发需要 Apple Developer Program。

不使用苹果签名时，可以打开 GitHub Pages 上的 PWA，在 Safari 分享菜单中选择“添加到主屏幕”。词库和学习进度保存在当前浏览器的本地数据库中。

## v0.2.0 多轮学习

每日新词数量取消 100 个上限。完成计划后可点击“再学一轮”，输入任意正整数作为本轮数量；支持连续多轮。本轮目标和起点保存在本机设置中，并包含在备份内；跨天恢复基础计划。加练不改变每日基础目标，实际新词与复习记录继续计入当天统计。学习页显示本轮新词进度，完成页显示当天累计和剩余词库。

## v0.3.0 工业术语词库

新增两张词表的 539 条有中文记录和 42 条无中文记录，跳过 3 条只有中文的数据。
在「词库 → 选择词库 → 英文/韩文专项（无中文）→ 单独学习本词库」专门背诵；
可按词库搜索、收藏、编辑，并在专项学习页返回日常队列。英韩混合词读韩文，纯英文读英文。
默认日常队列排除新增待补中文词条；重复词条保留已有释义和学习进度。每日计划完成后仍可继续多轮。
详细核对见 [导入清单](docs/technical-vocabulary-import.md)。

## v0.4.0 统一学习与打卡

所有来源合并为统一词库和学习队列，包含原无中文英韩词。支持独立轮次、新词/到期复习/混合、收藏和待强化错词练习，以及双向翻卡、拼写、听写、已有例句填空、人工词形表。

首页与统计页可打开打卡日历；完成至少一次学习后可以打卡，默认自动打卡。评分可撤销一次，当地日期的打卡、统计和本轮计数同时恢复。连续三次认识/简单后错词退出待强化列表，但保留历史错误。

加入单词详情、熟词/暂停学习、例句标签笔记编辑、批量标记、多工作表和列映射导入、30天热力图、未来七天复习预测、CSV/周报导出、阅读与背景控制、有效学习计时、恢复前自动本机快照。

当前版本仅使用本机学习数据与手动文件备份，不自动上传学习记录。场景练习和语法练习使用用户核对的内容，不自动编造释义或不规则活用。

完整边界与验收场景见 [v0.4.0 验收清单](docs/v0.4.0-acceptance.md)。
