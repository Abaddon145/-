# v0.4.0 统一学习与打卡

## 已实现的交付范围

- 所有来源词表共用统一词库和日常队列，取消原英韩无中文分组隔离。来源关系保留用于导入追溯，不删除既有释义与 FSRS 卡片。
- 新词、到期复习、混合学习；收藏、当前薄弱错词、词性、场景标签可创建独立轮次。本轮数量不设 100 上限；当天总统计继续累计。
- 翻卡双向学习、拼写、听写、例句填空、词形活用。填空使用含原词的既有例句；活用表须由用户核对后录入，不自动生成不规则变化。
- 学习页收藏、编辑、单词详情与撤销最近一次当天评分。撤销恢复卡片、用户词状态、当日统计、轮次计数、测试结果与必要的打卡状态。
- 切换导航、切后台或锁屏时暂停有效学习计时。
- 自动/手动打卡、当地日期去重、连续/最长天数、月历与累计里程碑。至少完成一次学习后才能打卡，不提供虚假补签。
- 错词连续三次“认识/简单”后移出当前待强化队列，历史错误次数保留；熟词和暂停词可在详情页恢复。
- 30 天热力图、已学不同词数、未来七天复习量、客观测试与自评记忆率分开、CSV 与 Markdown 周报。
- 多工作表、手动选列、英韩无中文导入、中文-only 跳过、重复预览与缺失字段补齐。重复导入保留已存在内容和复习状态。
- 例句/译文/笔记/场景标签编辑与批量标记。场景练习按已有词条标签筛选，不自动编造例句。
- 词与释义字号、行距、语速、专注模式、背景模糊/遮罩/缩放/位置。
- 原子备份、恢复前自动保留一次本机恢复快照、最近恢复撤销、上次备份提示和文件跨设备迁移。
- 使用应用自有缓存恢复离线启动，并在已下载新版时显示更新按钮；更新不清理 IndexedDB 学习数据。

## 外部服务边界

自动云同步未接入。当前可通过“文件 / iCloud Drive”保存备份，再在另一设备恢复；这是人工迁移，不是实时同步。
后续自动同步需要选择云服务、确认账户/数据存储和冲突规则。未配置之前，不向云端上传词库或学习记录。

## 验收

1. 旧设备升级后，新词总数包含此前英韩无中文来源；复习卡片、收藏和释义保持。
2. 收藏轮与普通轮各有进度，日常统计合计所有已保存评分。
3. 完成首个评分后打卡一次；再背十词仍只增加一个打卡日。跨天按设备当地日期记录。
4. 撤销首个评分后恢复“未学习”，当日次数归零且没有凭空打卡；不清除其他有效学习日。
5. 错词认识三次后退出待强化列表，历史错误仍可查看。
6. 恢复一个备份后可撤销恢复，回到恢复前词库、打卡和设置。
7. 输入错误拼写显示参考答案，保存后计入客观测试；自评与测试分开显示。
8. 锁屏/离开学习页一分钟不应被计入有效卡片学习时长。
9. 多表导入中中文-only 行跳过，英韩配对保留，重复词已有释义不覆盖。
10. 首次联网完成缓存后断网重开；有更新时点击更新并验证旧学习进度还在。
