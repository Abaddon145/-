基线：main `6c1129fb89f3c000123dd66ed5b9f3516e416432`（v0.6.1+10）。版本 v0.7.0+11，Drift schema 仍为 4。

## 完成内容

- 首页突出今日目标、继续学习、统计和常用入口；词库收拢学习范围，保留搜索、筛选、场景练习与收藏。
- 批量选择后底部固定显示数量、清除和生成操作；AI 面板固定保存按钮，额外字段默认不选，长内容分段展开。
- 设置集中显示 AI、学习外观、文件备份与撤销恢复；增加在线配图指南入口。
- 完整移除账户页面、认证客户端、后台同步观察器和 Supabase 依赖；旧云页面书签跳转至设置。只清理本机过期云绑定，不操作远端账户或历史云数据。

- 首次内置词库导入及普通文件导入改为事务内分批写入，减少 Web worker 逐词通信；重复词、原有内容、收藏及学习记录保留。Drift worker/Wasm 与 2.35.2 对齐。

## 浏览器验收与界限

配图使用实际 v0.7.0 UI，独立浏览器测试存储；AI 请求由 Playwright 拦截，使用自编 Mock 结果和无效演示密钥。没有真实模型 API Key，未执行计费生成。配图、联网失败/部分成功演示不构成模型质量与响应速度承诺。

Web 密钥使用上游标为实验的 WebCrypto 实现，同源脚本与受控设备仍可能读取，不等同服务器托管。原生设备使用安全存储，平台工程通过 `tool/configure_device_storage.dart` 配置 Keychain 与 Android 自动备份排除。

布局验证覆盖 320×568（1.5 倍字体、键盘）组件测试及 390×844 浏览器手机尺寸。PR #20 的 Flutter CI（run 38697943018）已完成 Web、iOS 模拟器构建和完整自动测试；未进行 iPhone/Android 真机操作和真实 DeepSeek 计费验收。
