# 账户与云同步已移除（v0.7.0）

应用不再提供注册、登录、云端上传或下载，不再初始化 Supabase SDK 或启动后台同步。
旧 `/settings/cloud` 书签跳转至设置；数据库打开时只清理 `cloud_` 前缀的过期标记，学习表保持不变。

本机学习记录、词库、FSRS、收藏、统计和打卡继续保留。跨设备迁移请在设置导出 JSON 备份，再在另一设备恢复。恢复会替换目标设备数据，并保留恢复前的一份撤销快照。

旧备份中云绑定标记会被忽略。DeepSeek API Key 独立保存在当前设备，代理凭证仍仅存运行会话；两者都不进入文件备份。

本次仅删除应用集成及仓库中的旧部署脚本，没有操作远端项目、删除远端账户、撤销远端会话或擦除历史云端数据。
