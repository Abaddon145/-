# v0.5.0 云同步

项目：韩语背单词，Supabase Seoul。客户端仅包含可公开的 publishable key；不包含数据库密码或 service-role key。

## 使用

设置 → 账户与云同步 → 注册（邮箱确认）或登录。
第一台设备选“保留本机 · 上传到云端”；第二台设备登录相同邮箱，选“保留云端 · 恢复到本机”。选择成功后启用自动保存。

应用打开期间约每 30 秒以及重新回到应用时检查。自动保存本机修改；发现云端更新时提示，点“现在同步”可接续。关闭应用期间不保证后台同步；换设备前点一次“现在同步”，确认成功。

两端同时修改时不自动合并。选择本机将替换云端；选择云端将替换本机，但保留一份恢复前的本机快照。可从设置撤销最近一次恢复。文件备份仍建议定期导出。

## 数据与安全

- 一个账户一份最新快照，包含词库、FSRS 卡片、日志、统计、收藏、错词、打卡、学习偏好、背景。
- `cloud_*` 同步标记不进入文件备份或云端。SDK 登录令牌独立存储；密码不入应用数据库、备份或快照。单次撤销记录和设备选中轮次不上传。
- 整份同步上限 20 MB；超过时提示缩小背景，本机学习不受影响。
- `korean_memo_snapshots` 开启 RLS；SELECT/INSERT/UPDATE 仅允许 `auth.uid() = user_id`；匿名访问关闭，无删除权限。
- `save_korean_memo_snapshot` 使用 SECURITY INVOKER 和空 search_path，显式授权 authenticated。版本 CAS 过期写入返回 40001，避免竞态覆盖。
- 恢复期间在本机数据库事务中重新比对摘要，避免慢网下载覆盖等待期间新产生的学习记录。
- 退出会停止云同步，保留本机数据。切换账户不会自动上传，首次必须选择数据起点。
- 恢复文件会清除同步基线；原账号登录态保留，但需重新选择本机/云端，避免误覆盖。

## 验证

云数据库事务测试：首次写入与 CAS 更新成功、过期版本被拒绝、跨账户查询不可见、跨账户插入/更新被拒绝。测试用户和数据在事务末尾回滚。安全和性能 advisors 无告警。

客户端测试覆盖初次连接、双端冲突、单端变化、摘要稳定、设备状态不上传以及恢复安全。GitHub CI 执行完整 Flutter analyze/test、双时区统计回归、网页及 iOS 模拟器构建。

后端 DDL 位于 `supabase/schema.sql`，由远端命名迁移 `korean_memo_cloud_sync` 应用；不是手工编造的 CLI 迁移时间戳文件。
