## 需求核对

| 需求 | 现有代码 | 本次处理 |
|---|---|---|
| 首页、词库、学习、统计、设置 | StatefulNavigationShell 五分支 | 保留；统一导航字体、选中态和高度 |
| 每日新词数量与学习计划 | SQLite 保存，默认 20 新词、100 次复习，复习优先 | 固定下拉改为整数输入，新词 1–100、复习 1–500；保存后重载学习队列 |
| 搜索、编辑、删除 | 韩语/中文/原形搜索；编辑；删除前确认 | 删除后刷新计划和统计；导入后刷新词库与学习队列 |
| 收藏、错词本 | 收藏状态；历史错误次数大于零进入错词本 | 评分成功后刷新词库，更新错词状态 |
| 单词单独录入、词性 | 录入表单；八种快捷词性；可输入其他词性 | 保留当前实现 |
| 多套界面风格 | 云白、青森、暮霞、深夜 | 新增纸笺、海盐，共六套；统一字体、边框、进度条和输入焦点样式 |
| 自定义背景 | JPG/PNG/WebP，2 MB，背景与设置随备份保存 | 增加预览、图片解码校验和 2000 万像素上限 |
| 统计 | 近七天数据；今日卡片 | 今日卡片使用当天正确率和时长；七天汇总独立显示 |

以上“现有代码”来自源码核对，尚未在本机运行验证，不等同于功能验收通过。

## 改动说明

- 学习评分成功时刷新首页数量、今日计划、七天统计和词库；失败时不刷新。
- 修复原每日计划下拉列表无法容纳备份中 7 个新词、37 次复习等合法数量的问题。
- 数量输入限制为数字，保存前验证范围；不更改现有数据结构或 FSRS 参数。
- 背景图片先解码取得尺寸，再保存；失败保留原背景，并显示错误反馈。
- 深色主题的文字使用 ColorScheme 的 onSurface 色；卡片继续保持高不透明度以保证背景上的阅读体验。
