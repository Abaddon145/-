# v0.8.0：界面、动效与便捷保存

## 用户可见变化

- 六套主题统一细边框、柔和卡片层次、标题与按钮字重；首页学习卡使用静态渐变，底部导航独立成圆角浮层。自定义背景和每页独立背景保留。
- 按压缩放 120ms；拖动超过 8px 就取消按压反馈，不抢占滚动手势。答案局部淡入/缩放 220ms，进度变化 300ms，收藏图标切换 160ms，底部面板进入 260ms/退出 180ms。没有整页滑入、循环装饰动画或列表逐项入场动画。
- 新增动效遵循系统减少动态效果/辅助导航设置。路由仍为零时长切换；面板覆盖底部导航，避免误切页。
- 学习评分区在窄屏或大字体时改为两列；揭示答案前后预留相同高度。长释义可展开，例句可收起；收藏星标反映实际状态。
- 活用和收藏通过按词条缓存的 provider 查询。输入、揭示和动画重建不重复读取活用设置。
- AI 解释生成后立即显示固定保存区。缺失的解释、搭配、例句等默认勾选，一次点击保存；已有内容默认保留。可用“选择内容”快速勾选，再应用选择；也可进入完整编辑与原内容对比。批量任务仍仅处理中文，疑似拼写不自动修改。
- AI 等待区显示耗时并可取消；错误按类型提供重试、设置或 DeepSeek 平台入口。服务端 Retry-After 秒数最多提示等待 300 秒，不自动重试。
- 每周备份提醒放在首页概览之后，可以延后 3 天或关闭。网页版下载后需确认文件已保存才更新导出时间；恢复前显示词条数、学习记录数与备份时间。

## 可靠性与兼容

HTTP 超时使用每条请求独立的取消信号，仍监听用户的整个任务取消；单条超时不会取消其他条目，保留 timeout 错误原因及已完成结果。学习页复用统一缺中文判定。

不改变数据库 schema、不清空记录，不改变 FSRS、每日学习上限或打卡逻辑。备份仍兼容原格式，本机导出时间及提醒偏好不随备份迁移；恢复与撤销恢复保留当前设备的这些信息。API Key 仍在独立设备存储中，不进入备份。

## 验证范围

新增测试覆盖：单条超时与部分成功；旧备份及撤销恢复的本机元信息；缺中文占位；时区及提醒延后；减少动态效果；拖动取消反馈；大字体评分区尺寸稳定；AI 计时组件销毁与手动重试；活用查询复用；备份快捷入口；解释一键保存与仅保存勾选例句。

浏览器验证使用隔离演示词库和 Mock DeepSeek 响应，不读取用户数据库、不发送真实计费请求。手机尺寸 Chromium 检查首页、答案、AI 面板、便捷保存、减少动态效果以及在线完成缓存后的离线重开。浏览器模拟不等于 iPhone 真机测试，未承诺所有机型达到固定帧率。

- `flutter analyze --no-pub`：无问题。

- 393×852 Chromium 手机视口：页面错误为 0；Mock 解释一键保存、关闭后原题揭示状态、减少动态效果下的面板往返、在线缓存后的断网重开全部通过。
- 截图已人工查看：首页、学习答案、AI 面板及底部保存区域。测试同时保留旧版截图用于对照。
