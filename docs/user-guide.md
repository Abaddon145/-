## 先从今天的学习开始

1. 打开 https://abaddon145.github.io/-/。首次使用会准备内置词库，等“开始今天的学习”可以点击后再开始。已有用户更新时会继续使用原本机数据库。

2. 底部五个入口分别是首页、词库、学习、统计和设置。首页的“今日学习”显示新词与复习目标，点击主按钮开始或继续当天学习。右上角滑杆图标可以调整每日计划，星光图标进入 AI 设置。

3. 每日新词默认 20 个、复习默认最多 100 次。新词目标可填写大于 100 的正整数；复习上限可设为 1–500。完成计划后仍可“再学一轮”，继续数量支持大于 100，不受 AI 每批 20 条的限制。

4. 建议先在设置导出一份备份。无需注册、登录或绑定账户，词库、复习计划、收藏、错词、统计和打卡保存在当前设备。

## 安装到手机与安全更新

1. iPhone：用 Safari 打开应用，点分享，再选“添加到主屏幕”。Android：用 Chrome 菜单中的“安装应用”或“添加到主屏幕”。以后从桌面图标进入。

2. 保持在同一个浏览器或已安装的应用中使用。不同浏览器、无痕窗口、手机桌面应用与浏览器标签页可能拥有各自的存储空间，不能假设数据会自动互通。

3. 更新时可点击“新版已就绪，点击更新”，或打开 https://abaddon145.github.io/-/update.html?v=0.7.0。安全更新页更新应用缓存，不清除 IndexedDB 学习数据。

4. 首次加载及获取新版本需要网络。正常加载并使用过后，已缓存的普通背词可离线使用；AI 生成需要联网。避免直接清除网站数据：浏览器清理或卸载可能删除本机词库、记录和已保存密钥。换设备请使用文件备份。

## DeepSeek 只配置一次

1. 在首页点星光图标，或进入“设置 → AI 学习助手设置”。连接方式保留“DeepSeek 直连”，无需填写代理地址或代理访问凭证。

2. 从 https://platform.deepseek.com/api_keys 创建并复制完整 API Key，粘贴到“DeepSeek API Key”。应复制创建时显示的完整密钥；Tracking ID 是标识符，不能用于调用。

3. 点击“保存设置”。密钥保存在当前设备，同一浏览器刷新、关闭后重开会自动读取。词库备份不包含密钥，在另一设备恢复词库后需单独配置。清除网站数据、结束无痕会话或更换浏览器后也可能需要重填。

4. 点击“连接测试”检查密钥和模型是否可用。它只查询模型列表，不生成内容。默认模型为 deepseek-flash；如果账户未提供该模型，在“高级选项”填写开放平台实际支持的模型名。

5. 下方“默认语境”可选日常韩语、物流与仓储、工厂设备、生产与工业术语、商务邮件或自定义语境。使用自己的个人设备；密钥通过 HTTPS 只发送到 DeepSeek 官方 API。

6. 需要换密钥时重新粘贴并保存。点击“清除已保存密钥”可删除这台设备上的密钥，并停止本机批量任务的排队与请求。清除不会撤销开放平台中的密钥；若要停用该 API Key，请在 DeepSeek 开放平台管理。


[查看界面配图：DeepSeek 只配置一次](https://abaddon145.github.io/-/guide.html)


## 搜索、收藏与整理词库

1. 进入“词库”，在顶部输入单词、中文或标签，稍等片刻即可看到搜索结果。右侧叉号清除搜索。下方横向筛选包括全部、收藏、错词本、待补中文。

2. 点词条进入详情，可查看例句、笔记、最近复习、熟词或暂停状态。星号用于收藏；右侧更多菜单可“编辑 / 标记词性”或删除。删除会同时删除该词的本机学习记录，操作前请核对。

3. 点右下角“录入单词”填写韩语、中文和词性。需要批量导入时，点右上角三个点 → 导入 Excel 词库。可选择工作表、核对字段映射并预览后确认。

4. Excel 至少准备“韩语单词”“中文释义”两列，也识别 단어 / 뜻 / word / meaning 等列名。英韩术语缺中文时会保留来源和占位状态，可后续人工编辑或用 AI 补充。导入复用已有词，不自动改动其学习计划。

5. “学习范围与场景”默认折叠，展开后可按当前结果或工作场景开始练习。错词连续三次认识或简单后会退出待强化队列，但保留历史错误。

## AI 补全：先对比，再选择保存

1. 在词库打开一个词条，点“AI 补全”。先选语境；工业术语建议补充设备、部件或原句。需要多个例句时，展开“生成选项”选择每组 1–3 个。点“生成建议”。

2. 生成后，中文释义、词性、原形及例句展示“原内容”和可编辑的“AI 建议”。缺失的主要字段可默认勾选，已有内容默认不勾选。先检查含义和译文，再编辑并保留你愿意保存的勾选项。

3. 常见搭配、工作例句、用法、语法、易混淆词和英韩对应在“更多字段与说明”中展开。额外字段默认不选，需看过后主动勾选。底部固定按钮显示将保存的字段数量，长内容滚动或键盘弹出时也可操作。

4. 点“重新生成候选”可以比较多个候选，点候选编号切换。关闭后重新进入时，符合当前词条、语境与版本的未保存建议可从本机缓存恢复；改了原词内容后旧建议失效。

5. 点击“保存选中的 N 个字段”只更新被选内容。释义或例句保存不会给学习自动评分，不增加学习计数，不改变 FSRS 或打卡。内容标记为“AI 生成·用户已确认”。

6. 疑似 clrculation、acuum 等异常拼写会提示候选或请求更多语境。原词不会自动改写。只有你主动选择拼写候选并单独确认后才可修改，重复词冲突会阻止保存；原词被修改或删除时也会要求处理冲突。

## AI 批量补中文与结果审核

1. 进入“词库 → 待补中文”，可继续输入搜索条件缩小范围。逐条点复选框，或点“选择当前结果”。底部显示已选数量，可“清除选择”。应用不会默认处理整个词库。

2. 点击底部“AI 批量补中文”，选择语境，创建本机任务。每个任务最多 20 条；超过时只取当前前 20 条，其余可以继续下一批。该限制只针对 AI，不限制每天背词数。

3. 进入任务页后点“开始 / 仅重试失败及未完成”。生成并发最多 2，逐条结果立即保存到本机。任务页显示待确认、失败、取消和已保存等状态，部分失败不会丢掉成功结果。

4. 点“取消排队与请求”停止尚未开始的条目，并终止正在进行的可取消请求。重新开始只处理失败或未完成项。关闭后重新打开，在“设置 → 本机 AI 任务”找到未完成任务，由你决定是否继续。

5. 点“成功·待确认”的结果进入审核，检查并选择保存。批量默认只针对中文释义。疑似拼写或需要更多语境时不会默认选择中文，需要先核对。已有非占位中文不会自动覆盖。

6. 如果生成期间原词被改动，应用展示冲突并要求重新对比、确认；若原词已删除则不能写回。同一任务不能重复启动。本页配图含演示的成功项、疑似拼写项与失败项，用于说明审核方式。

## 学习中用 AI 解释，再回到原题

1. 在学习页点“AI 解释”，底部面板打开后有效学习计时暂停。选择语境并生成，可看简明含义、搭配、简单例句、工作例句与必要的用法说明。

2. “更简单”“工作场景”“易混淆词”“例句解析”会按对应方向重新生成，需要联网。相同词条、语境、任务类型、例句数量及提示词版本优先使用仍有效的本机缓存，也可主动重新生成。

3. 如果要保留解释或例句，进入字段预览并只勾选需要的内容，核对后保存。不保存也可以直接关闭。生成、打开和关闭面板都不会自动评分或完成这道题。

4. 点击面板右上角叉号返回。当前词、已输入答案、揭示状态和本轮进度保留；仅在学习页可见且应用位于前台时恢复计时。若切到其他页面或将应用放到后台，关闭面板也不会误计学习时间。


[查看界面配图：学习中用 AI 解释，再回到原题](https://abaddon145.github.io/-/guide.html)


## 复习评分与继续学习

1. 学习页支持翻卡、拼写、听写等已有练习模式。按题目要求先回忆或输入，再揭示答案；AI 是辅助解释，不会代替你判断认识程度。

2. 根据实际记忆情况选择忘记、困难、认识或简单，FSRS 会据此安排后续复习。需要纠正上一次评分时使用撤销一次，相关本轮计数、当天统计和打卡会随之恢复。

3. 完成当前目标后，可继续新词、到期复习或混合练习，填写下一轮数量。“每日计划”是基础目标，“再学一轮”是额外练习；实际完成的学习仍计入当天统计。

4. 普通背词直接使用本机数据库。未配置密钥、DeepSeek 不可用或断网时仍可继续已缓存应用的普通学习；此时 AI 生成会提示服务状态，不阻断正常复习。

## 备份、换设备与撤销恢复

1. 进入“设置”，向下滚动到“文件备份与迁移”。建议定期点“备份学习进度”，将 JSON 文件保存到系统“文件”或你选择的文件服务。页面显示最近一次导出时间。

2. 备份包括词库、学习记录、FSRS、收藏、错词、统计、打卡、学习设置和外观。需要携带 AI 建议、已确认扩展内容与任务时，先打开“文件备份包含 AI 数据”。旧备份没有 AI 数据也能恢复。

3. API Key、代理凭证不进入文件备份。恢复词库不会覆盖当前设备独立保存的 DeepSeek 密钥；新设备需要单独填写自己的密钥。

4. 换设备时，先将备份文件带到新设备，再选择“恢复学习进度”并选 JSON。恢复会替换目标设备的整个本机数据集，请在确认前先备份目标设备原有数据。支持的文件大小不超过 20 MB。

5. 恢复前应用会保留一份本机快照。若发现恢复错了，可点“撤销最近一次恢复”返回恢复前状态。只保留最近一次可撤销快照，不能替代长期保存的备份文件。

6. 账户与自动云同步已从新版移除。保存到 iCloud Drive 等文件服务是你主动保存文件，不是应用自动同步。升级不远程删除旧服务中可能存在的历史云端数据。

## 外观、阅读和发音

1. 在“设置 → 外观风格”选择云白、青森、暮霞、纸笺、海盐或深夜，或上传不超过 2 MB 的自定义背景。页面切换沿用独立背景和无滑入叠加的方案。

2. “阅读、发音与背景调整”可调整字号、语速和背景显示，按自己的阅读习惯选择专注模式。长内容可以滚动和分段展开；AI 面板的保存按钮固定在下方。

3. 韩语发音依赖系统或浏览器提供的 ko-KR 语音。若没有声音，检查系统音量、静音、浏览器播放限制及韩语语音包。纯英文词会按可用英文语音朗读，英韩混合词优先读韩文。


[查看界面配图：外观、阅读和发音](https://abaddon145.github.io/-/guide.html)


## 学习统计与打卡

1. 底部“统计”查看累计学习、当天表现、热力图和未来复习预测。首页与统计页都可以进入打卡日历。完成至少一次学习后可以打卡，默认开启学习后自动打卡。

2. 打开 AI 面板的时间不计入有效学习计时；将应用放到后台或离开学习页也暂停。AI 建议保存不会给统计增加学习记录。日期按本机当地日期归属。

3. 更换设备后，只有恢复含学习记录的备份才会带来原来的统计和打卡。安装同一个网页并不会自动获得另一设备上的数据。

## 常见问题与核对清单

1. 页面还是旧版：先保存备份，再打开安全更新链接；更新完成后重新进入。不要用“清除所有网站数据”代替更新。

2. 重开后提示没密钥：确认使用同一个浏览器或桌面应用、不是无痕模式，且没有清除站点数据。重新填写后点击“保存设置”，仅输入未保存不会生效。若提示无法保存，请检查浏览器存储权限。

3. 401 或密钥无效：复制完整 API Key，核对空格、是否已停用；不要填写 Tracking ID。余额不足：到 DeepSeek 开放平台检查 API 余额。模型不可用：在高级选项核对账户支持的模型名称。

4. 断网、超时或限流：普通学习可继续；联网或稍后再手动重试 AI。批量只重试失败及未完成项。兼容服务或浏览器跨域规则变化可能影响直连，可使用可选私有代理，详见仓库 AI 部署文档。

5. 结果不合适：换成更具体的工作语境，或编辑建议、取消对应字段勾选，或重新生成比较候选。AI 输出需要人工核对，没有接入真实词典检索时不会标注“官方词典已验证”。

6. 保存冲突：重新加载当前词并对比确认，避免覆盖刚刚人工编辑的内容。已保存建议不能重复保存，原词删除后也不能写入。疑似拼写应先核对原表、设备名称或上下文。

7. 清理 AI 缓存：只清理未保存、且不属于批量任务的建议；保留已确认内容与任务。若想换 API Key，请使用“清除已保存密钥”或直接保存新密钥。

8. 本手册截图来自 v0.7.0 的实际运行界面。所有 AI 内容均为专门编写的 Mock 演示，使用无效演示密钥并拦截请求；没有调用真实计费模型。真实生成内容和速度由服务、模型、网络与语境决定。验证覆盖浏览器手机尺寸与组件布局，尚不代表 iPhone/Android 真机的全部系统行为。
